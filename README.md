# 영광 기후 리포트

Next.js 기반의 영광군(기상청 ASOS 지점번호 252) 기후 비교 대시보드입니다.

## 실행

1. Node.js 18 이상 설치
2. 프로젝트 루트에서 `npm install`
3. `.env.example`을 복사해 `.env.local` 생성
4. `.env.local`에 발급받은 기상청 API허브 인증키 입력

```env
KMA_API_KEY=발급받은_인증키
```

5. `npm run dev` 후 http://localhost:3000 접속

## 데이터 소스 / 구현 메모

API허브에서 아래 두 API의 활용신청이 필요합니다.

- 실제 관측: `kma_sfcdd3.php` (지상관측 > 일자료(기간 조회))
  - 공백 구분 고정 컬럼: `TA_AVG`(11번째), `TA_MAX`(12번째), `TA_MIN`(14번째), `SS_DAY`(33번째), `RN_DAY`(39번째)
  - 결측: 기온 `-99.0`, 일조 `-9.0` / 강수 `-9.0`은 "강수 없음"(0)으로 처리
  - 기온·일조가 모두 결측인 날은 장비 결측일로 보고 강수도 결측 처리
- 평년: `sfc_norm1.php` (지상 평년값 조회, `norm=D`, `tmst=2021` = 1991~2020)
  - CSV: `ST,STN,MM,DD,TA,TA_MAX,TA_MIN,RN,...,SS` / 결측 `-99.9`
  - 1년치를 한 번에 받아 월-일로 매칭 (해를 넘기는 기간, 2/29 포함)
  - 영광(252)은 1991~2020 이전 평년값이 제공되지 않음
- 평년 강수일수: `sfc_norm1.php` (`norm=M` 월별 평년값의 `RD_01`, `RD_10`)
  - 일별·순별 평년값에는 강수일수가 없어 월별 값을 사용
- 영광 ASOS 지점번호 252

## 집계 규칙

- 평균기온: 유효한 일평균기온의 평균
- 기간 최고/최저기온: 유효한 일최고기온 중 최댓값 / 일최저기온 중 최솟값과 발생일. 비교 기준은 발생일의 일별 평년 최고/최저기온
- 누적 강수량: 유효한 일강수량 합계
- 강우일수: 일강수량 0.1mm 이상 / 1.0mm 이상인 날 수 (강수 결측일 제외). 평년은 월별 평년 강수일수 × (기간 내 그 달 일수 ÷ 그 달 전체 일수)의 합으로 환산한 근사값
- 누적 일조시간: 유효한 일조시간 합계
- 결측값은 0으로 대체하지 않고 평균·합계에서 제외하며, 결측 일수를 경고로 표시합니다.
- 평년값은 선택 기간의 일별 평년값 평균(기온) / 합계(강수·일조)입니다.
- 한 번에 최대 366일 조회
- API 인증키는 서버 환경변수로만 사용합니다.

## 엑셀 양식 다운로드

`templates/`의 기존 양식(평균기온·강수량·일조시수, 1987~)에 선택 기간의 일자료를 채워 내려받습니다 (`/api/excel?type=temp|rain|sunshine&start&end`, 최대 10년).

- 칸 위치: `N월` 시트, `(일 + 2)`행(1일 = 3행), 2행 `YYYY년` 열. 그 달 마지막 날까지만 채우고 월계·월평균 행은 건드리지 않음
- 입력 규칙(기존 파일과 동일): 기온·일조 결측은 기존 칸 유지, 강수 없는 날은 빈칸
- 연도 열이 없으면 직전 연도 열 뒤에 새 열을 삽입. 통계 열(평년 등)은 오른쪽으로 밀리고 다른 시트의 참조 수식도 함께 이동, 월계·월평균 수식은 직전 연도 열에서 복사
- 수식 결과는 파일을 열 때 재계산. 원본의 프린터 설정 데이터는 유지되지 않음
- 생성 파일은 서버에 저장하지 않고 응답으로 바로 반환

### 예정: 사용 중인 파일 업로드 방식

지금은 항상 `templates/`의 원본에서 시작하므로, 기간을 12월만 고르면 10~11월은 원본 상태(빈칸)로 남습니다.
사용자가 최신 엑셀 파일을 업로드하면 그 파일에 선택 기간을 채워 바로 돌려주는 방식으로 바꿀 예정입니다.

- 파일 선택 → 기간 선택 → 버튼 → 채운 파일 즉시 다운로드 (원래 파일명 유지)
- 파일 종류는 시트 1행 제목(평균기온/강수량/일조시수)으로 자동 판별
- 업로드 파일은 메모리에서만 처리하고 저장하지 않음 (Vercel 요청 본문 4.5MB 제한, 현재 파일은 약 200KB)
- 업로드하지 않으면 지금처럼 `templates/` 원본 사용
