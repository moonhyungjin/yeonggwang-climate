# 영광 기후 비교 MVP

Next.js 기반의 영광군(기상청 ASOS 지점번호 252) 기후 비교 대시보드입니다.

## 실행

1. Node.js 18 이상 설치
2. 프로젝트 루트에서 `npm install`
3. `.env.example`을 복사해 `.env.local` 생성
4. `.env.local`에 발급받은 기상청 API허브 인증키 입력

```env
KMA_API_KEY=발급받은_인증키
```

5. `npm run dev` 후 http://localhost:3000 접속

## 데이터 소스 / 구현 메모

API허브에서 아래 두 API의 활용신청이 필요합니다.

- 실제 관측: `kma_sfcdd3.php` (지상관측 > 일자료(기간 조회))
  - 공백 구분 고정 컬럼: `TA_AVG`(11번째), `SS_DAY`(33번째), `RN_DAY`(39번째)
  - 결측: 기온 `-99.0`, 일조 `-9.0` / 강수 `-9.0`은 "강수 없음"(0)으로 처리
  - 기온·일조가 모두 결측인 날은 장비 결측일로 보고 강수도 결측 처리
- 평년: `sfc_norm1.php` (지상 평년값 조회, `norm=D`, `tmst=2021` = 1991~2020)
  - CSV: `ST,STN,MM,DD,TA,...,RN,...,SS` / 결측 `-99.9`
  - 1년치를 한 번에 받아 월-일로 매칭 (해를 넘기는 기간, 2/29 포함)
  - 영광(252)은 1991~2020 이전 평년값이 제공되지 않음
- 영광 ASOS 지점번호 252

## 집계 규칙

- 평균기온: 유효한 일평균기온의 평균
- 누적 강수량: 유효한 일강수량 합계
- 누적 일조시간: 유효한 일조시간 합계
- 결측값은 0으로 대체하지 않고 평균·합계에서 제외하며, 결측 일수를 경고로 표시합니다.
- 평년값은 선택 기간의 일별 평년값 평균(기온) / 합계(강수·일조)입니다.
- 한 번에 최대 366일 조회
- API 인증키는 서버 환경변수로만 사용합니다.

## 주의

이 MVP는 API 연동 구조와 화면을 빠르게 검증하기 위한 출발점입니다. 실제 배포 전에 API 원문 응답의 헤더 및 강수량·평년 필드 제공 여부를 반드시 확인하고 매핑을 확정해야 합니다.
